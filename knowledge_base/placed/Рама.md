# Рама

Документ описывает алгоритм выбора рамы: материал, цвет и ширину профиля. Правила должны давать один воспроизводимый результат без ручного выбора между несколькими вариантами.

Цвет паспарту, наличие паспарту, стекло и shadow box определяются отдельными документами.

## Входные параметры

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Тип работы | `poster`, `photo`, `watercolor`, `engraving`, `botanical`, `canvas`, `volumetric` | Ограничивает материал и характер профиля. |
| Стиль интерьера | `minimal`, `scandi`, `japandi`, `contemporary`, `loft`, `modern_vintage`, `neoclassic`, `universal` | Задает базовый порядок цветов и материалов. |
| Размерный профиль | `small`, `medium`, `large`, `extra_large` | Определяет ширину профиля. |
| Заполненность кадра | `low`, `medium`, `high` | Уточняет ширину профиля. |
| Светлота изображения | `light`, `medium`, `dark` | Участвует в скоринге цвета и материала рамы. |
| Насыщенность изображения | `low`, `medium`, `high` | Для ярких изображений ограничивает раму нейтральными вариантами. |
| Монохромность | `monochrome`, `color` | Для монохромных изображений включает отдельное жесткое правило по цвету рамы. |
| Цветовая температура | `warm`, `neutral`, `cold` | Сейчас не выбирает цвет напрямую; используется только в дереве решений и будущих правилах. |

Если стиль интерьера равен `universal`, алгоритм использует правила `contemporary`.

## Библиотека рам

Каждая рама имеет фиксированные свойства. Алгоритм выбирает только из этой библиотеки.

| ID | Название | Материал | Цветовая семья | Светлота | HEX |
| --- | --- | --- | --- | --- | --- |
| `black_aluminum` | Черный алюминий | aluminum | black | dark | `#111111` |
| `black_wood` | Черное дерево | wood | black | dark | `#111111` |
| `white_wood` | Белое дерево | wood | white | light | `#F4F1EA` |
| `champagne_aluminum` | Шампань | aluminum | champagne | light | `#D8B65C` |
| `silver_aluminum` | Серебро | aluminum | silver | light | `#BFC3C7` |
| `light_oak` | Светлый дуб | wood | oak | light | `#C2A77E` |
| `oak` | Дуб | wood | oak | medium | `#A6753F` |
| `walnut` | Орех | wood | walnut | medium | `#6F4A2D` |
| `dark_walnut` | Темный орех | wood | walnut | dark | `#3B281D` |
| `gold` | Золото | wood | gold | medium | `#C3A15A` |

`gold` допускается только для `neoclassic`. Для остальных стилей оно исключается до выбора цвета.

В `neoclassic` алюминиевые рамы не используются. Это жесткое ограничение, которое не отменяется последующими фильтрами.

## Общий порядок алгоритма

Алгоритм выполняется строго в этом порядке:

1. Нормализовать стиль интерьера.
2. Взять полный набор рам из библиотеки.
3. Применить жесткие запреты.
4. Оценить оставшиеся рамы скоринговой моделью.
5. Выбрать раму с максимальным количеством баллов.
6. Рассчитать ширину профиля по размерному профилю, заполненности кадра и материалу.
7. Вернуть итоговую раму и дерево решений.

Жесткие запреты отвечают за то, что нельзя использовать. Скоринг отвечает за то, что лучше или хуже в конкретном контексте. Светлота изображения, материал, интерьер, монохромность, температура и цвет паспарту больше не выбрасывают кандидатов напрямую, если это не описано как hard rule.

## Шаг 1. Нормализация стиля

| Входной стиль | Используемый стиль |
| --- | --- |
| `minimal` | `minimal` |
| `scandi` | `scandi` |
| `japandi` | `japandi` |
| `contemporary` | `contemporary` |
| `loft` | `loft` |
| `modern_vintage` | `modern_vintage` |
| `neoclassic` | `neoclassic` |
| `universal` | `contemporary` |
| неизвестное значение | `contemporary` |

## Шаг 2. Стартовый набор рам

Скоринговая модель начинает не с короткого интерьерного списка, а со всей библиотеки рам. Это нужно, чтобы черная рама могла конкурировать в разных стилях, а не исчезала слишком рано.

| Порядок резерва | Рама |
| ---: | --- |
| 1 | `black_aluminum` |
| 2 | `black_wood` |
| 3 | `white_wood` |
| 4 | `light_oak` |
| 5 | `oak` |
| 6 | `walnut` |
| 7 | `dark_walnut` |
| 8 | `champagne_aluminum` |
| 9 | `silver_aluminum` |
| 10 | `gold` |

## Шаг 3. Жесткие исключения

Исключения применяются в указанном порядке.

| Приоритет | Условие | Действие |
| ---: | --- | --- |
| 1 | Стиль не `neoclassic` | Удалить `gold` из списка кандидатов. |
| 2 | Стиль `neoclassic` | Удалить все рамы с `material = aluminum`. |
| 3 | Стиль `japandi`, `modern_vintage` или `neoclassic` | Удалить `silver_aluminum`. |
| 4 | Стиль `loft`, `japandi` или `neoclassic` | Удалить `champagne_aluminum`. |
| 5 | `artwork_type = canvas` | Оставить только рамы с `material = wood`. |
| 6 | `artwork_type = volumetric` | Оставить только рамы с `material = wood`. |
| 7 | `size_profile = extra_large` | Удалить `white_wood`. |
| 8 | `monochrome = monochrome` | Оставить только цветовые семьи `black`, `white`, `silver`. |

Если hard rules оставляют пустой список, используется резерв:

| Условие | Резервная рама |
| --- | --- |
| `canvas`, `volumetric` или `neoclassic` | `black_wood` |
| любой другой случай | `black_aluminum` |

## Шаг 4. Скоринг

После hard rules каждая оставшаяся рама получает баллы. Побеждает кандидат с максимальной суммой.

### 4.1. Баллы за интерьер

Интерьер задает базовую уместность рамы. Баллы не являются запретом: рама с низким интерьерным баллом может победить за счет контраста, монохромности или материала.

| Стиль | Основные предпочтения |
| --- | --- |
| `minimal` | черный алюминий, белое дерево, затем спокойные металлы |
| `contemporary` | черный алюминий и черное дерево, затем орех и спокойные светлые варианты |
| `scandi` | светлый дуб, белое дерево, дуб |
| `japandi` | светлый дуб, дуб, орех, темный орех |
| `modern_vintage` | орех, темный орех, дуб |
| `loft` | черный алюминий, черное дерево, темный орех |
| `neoclassic` | орех, золото, темный орех |

### 4.2. Материал по типу работы

Материал больше не является обычным фильтром, кроме `canvas` и `volumetric`, где дерево обязательно.

| Тип работы | Приоритет материала | Балльная логика |
| --- | --- | --- |
| `poster` | aluminum | aluminum получает бонус, wood допустим как fallback |
| `photo` | aluminum | aluminum получает бонус, wood допустим как fallback |
| `watercolor` | wood | wood получает бонус, aluminum допустим как fallback |
| `engraving` | wood | wood получает бонус, aluminum допустим как fallback |
| `botanical` | wood | wood получает бонус, aluminum допустим как fallback |
| `canvas` | wood | только wood |
| `volumetric` | wood | только wood |

### 4.3. Монохромность

Для монохромного изображения допустимы только черный, белый и серебристый цвет рамы. Внутри этого набора черная рама получает высокий бонус, чтобы она реально использовалась, а не проигрывала белому и серебру по светлоте.

Если интерьер `japandi`, `modern_vintage` или `neoclassic`, серебро уже удалено hard rule до скоринга.

### 4.4. Светлота изображения

Светлота не фильтрует рамы напрямую.

| Условие | Логика |
| --- | --- |
| Светлая или очень светлая работа + `minimal`, `contemporary`, `loft` | Черный цвет получает сильный бонус за контраст. |
| Светлая или очень светлая работа + `scandi`, `japandi`, `modern_vintage`, `neoclassic` | Дерево получает сильный бонус; белый и серебро штрафуются, чтобы не становиться автоматическим выбором. |
| Темная работа | Светлые рамы получают умеренный бонус, черный получает небольшой штраф. |
| Средняя светлота | Средние тона и черный получают умеренный бонус. |

### 4.5. Насыщенность, температура и паспарту

| Условие | Логика |
| --- | --- |
| Высокая насыщенность изображения | Черный получает высокий бонус; белый и дубовые нейтрали получают умеренный бонус; цветные металлы штрафуются. |
| Теплое изображение | Дерево получает бонус; серебро штрафуется. |
| Холодное изображение | Черный получает бонус; серебро получает небольшой бонус, если не запрещено hard rules. |
| Теплое паспарту | Серебро получает сильный штраф; дерево и черный получают бонус. |

## Шаг 5. Итоговый выбор цвета

Алгоритм сортирует кандидатов по сумме баллов. При равенстве баллов используется стабильный резервный порядок из шага 2 и интерьерная уместность.

## Шаг 6. Размер профиля

Ширина профиля зависит от размерного профиля, заполненности кадра и материала выбранной рамы.

| Размерный профиль | Заполненность кадра | Дерево | Алюминий |
| --- | --- | ---: | ---: |
| `small` | `low` | 15 мм | 10 мм |
| `small` | `medium` | 15 мм | 10 мм |
| `small` | `high` | 20 мм | 12 мм |
| `medium` | `low` | 15 мм | 10 мм |
| `medium` | `medium` | 20 мм | 12 мм |
| `medium` | `high` | 20 мм | 12 мм |
| `large` | `low` | 20 мм | 12 мм |
| `large` | `medium` | 30 мм | 15 мм |
| `large` | `high` | 30 мм | 15 мм |
| `extra_large` | `low` | 30 мм | 15 мм |
| `extra_large` | `medium` | 40 мм | 20 мм |
| `extra_large` | `high` | 50 мм | 20 мм |

Если заполненность кадра неизвестна, используется `medium`.

## Шаг 7. Выход алгоритма

Алгоритм возвращает объект `FrameSpec`.

```yaml
FrameSpec:
  id: string
  name: string
  material: wood | aluminum
  color_family: string
  tone: light | medium | dark
  hex: string
  width_mm: integer
  profile: flat | natural_wood | classic
```

`profile` определяется по выбранной раме:

| Условие | profile |
| --- | --- |
| `material = aluminum` | `flat` |
| `id = gold` | `classic` |
| прочие деревянные рамы | `natural_wood` |

## Дерево решений

В дереве решений нужно показывать:

1. Входные параметры: тип работы, стиль, размерный профиль, заполненность, светлота, насыщенность, монохромность.
2. Нормализованный стиль интерьера.
3. Стартовый набор рам из библиотеки.
4. Какие hard rules применились и какие кандидаты остались.
5. Какие кандидаты получили наибольшие баллы и за счет каких факторов.
6. Какая рама выбрана итогово.
7. Какая ширина профиля выбрана и по какой строке таблицы.

## Примеры

| Вход | Итог |
| --- | --- |
| Постер, минимализм, средний размер, высокая заполненность, темное изображение | `black_aluminum`, 12 мм |
| Фото, сканди, малый размер, низкая заполненность, светлое изображение | деревянная рама, чаще `light_oak` или `oak`, 15 мм |
| Черно-белое фото, современный интерьер, большой размер, средняя заполненность, темное изображение | `black_aluminum`, 15 мм |
| Черно-белое изображение, Japandi / Modern Vintage / неоклассика | только черная или белая рама, без серебра |
| Акварель, лофт, светлое изображение, средний размер, низкая заполненность | черная рама или темное дерево, без шампани |
| Холст, минимализм, большой размер, высокая заполненность | `white_wood`, 30 мм |
| Акварель, сканди, очень большой размер, высокая заполненность, светлое изображение | `light_oak`, 50 мм |

## Ограничения текущей версии

- Алгоритм пока выбирает только из базовой библиотеки рам.
- Золото определяется только интерьерным правилом `neoclassic`; автоматическое распознавание золотых элементов изображения пока не используется.
- Цветовая температура изображения учитывается в скоринге, но не является hard rule.
- Реальные артикулы багета, глубина профиля, наличие складских остатков и цена пока не учитываются.
