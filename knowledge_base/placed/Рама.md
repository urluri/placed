# Рама

Документ описывает алгоритм выбора рамы: материал, цвет и ширину профиля. Правила должны давать один воспроизводимый результат без ручного выбора между несколькими вариантами.

Цвет паспарту, наличие паспарту, стекло и shadow box определяются отдельными документами.

## Входные параметры

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Тип работы | `poster`, `photo`, `watercolor`, `engraving`, `botanical`, `canvas`, `volumetric` | Ограничивает материал и характер профиля. |
| Стиль интерьера | `minimal`, `scandi`, `japandi`, `contemporary`, `loft`, `modern_vintage`, `neoclassic`, `universal` | Задает базовый порядок цветов и материалов. |
| Размерный профиль | `small`, `medium`, `large`, `extra_large` | Определяет ширину профиля. |
| Заполненность кадра | `low`, `medium`, `high` | Уточняет ширину профиля. |
| Светлота изображения | `light`, `medium`, `dark` | Фильтрует цвет рамы по светлоте. |
| Насыщенность изображения | `low`, `medium`, `high` | Для ярких изображений ограничивает раму нейтральными вариантами. |
| Монохромность | `monochrome`, `color` | Для монохромных изображений включает отдельное жесткое правило по цвету рамы. |
| Цветовая температура | `warm`, `neutral`, `cold` | Участвует в приоритетном правиле выбора рамы `champagne_aluminum`. |

Если стиль интерьера равен `universal`, алгоритм использует правила `contemporary`.

## Библиотека рам

Каждая рама имеет фиксированные свойства. Алгоритм выбирает только из этой библиотеки.

| ID | Название | Материал | Цветовая семья | Светлота | HEX |
| --- | --- | --- | --- | --- | --- |
| `black_aluminum` | Черный алюминий | aluminum | black | dark | `#111111` |
| `black_wood` | Черное дерево | wood | black | dark | `#111111` |
| `white_wood` | Белое дерево | wood | white | light | `#F4F1EA` |
| `champagne_aluminum` | Шампань | aluminum | champagne | light | `#D8B65C` |
| `silver_aluminum` | Серебро | aluminum | silver | light | `#BFC3C7` |
| `light_oak` | Светлый дуб | wood | oak | light | `#D4B789` |
| `oak` | Дуб | wood | oak | medium | `#A6753F` |
| `walnut` | Орех | wood | walnut | medium | `#6F4A2D` |
| `dark_walnut` | Темный орех | wood | walnut | dark | `#3B281D` |
| `gold` | Золото | wood | gold | medium | `#C3A15A` |

`gold` допускается только для `neoclassic`. Для остальных стилей оно исключается до выбора цвета.

В `neoclassic` алюминиевые рамы не используются. Это жесткое ограничение, которое не отменяется последующими фильтрами.

## Общий порядок алгоритма

Алгоритм выполняется строго в этом порядке:

1. Нормализовать стиль интерьера.
2. Получить упорядоченный список рам по стилю интерьера.
3. Применить жесткие исключения.
4. Проверить приоритетное правило выбора рамы `silver_aluminum`.
5. Проверить приоритетное правило выбора рамы `oak`.
6. Проверить приоритетное правило выбора рамы `champagne_aluminum`.
7. Проверить приоритетное правило выбора черной рамы.
8. Проверить приоритетное правило выбора рамы `light_oak`.
9. Проверить приоритетное правило выбора белой рамы.
10. Если приоритетные правила не сработали, применить ограничения по типу работы и материалу.
11. Если приоритетные правила не сработали, применить фильтр по светлоте изображения.
12. Выбрать первый вариант из оставшегося списка.
13. Рассчитать ширину профиля по размерному профилю, заполненности кадра и материалу.
14. Вернуть итоговую раму и дерево решений.

Если на любом этапе фильтр дает пустой список, этот фильтр отменяется, а алгоритм продолжает работу с результатом предыдущего этапа. Исключение: hard-фильтры `canvas`, `volumetric`, запрет `gold` вне `neoclassic`, запрет алюминия в `neoclassic`, запрет белой рамы для `extra_large` и правило монохромного изображения не отменяются.

## Шаг 1. Нормализация стиля

| Входной стиль | Используемый стиль |
| --- | --- |
| `minimal` | `minimal` |
| `scandi` | `scandi` |
| `japandi` | `japandi` |
| `contemporary` | `contemporary` |
| `loft` | `loft` |
| `modern_vintage` | `modern_vintage` |
| `neoclassic` | `neoclassic` |
| `universal` | `contemporary` |
| неизвестное значение | `contemporary` |

## Шаг 2. Базовый порядок рам по интерьеру

Список упорядочен от самого предпочтительного варианта к запасному. После всех фильтров выбирается первый оставшийся вариант.

| Стиль            | Упорядоченный список рам                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------- |
| `minimal`        | `black_aluminum`, `white_wood`, `champagne_aluminum`, `silver_aluminum`                        |
| `contemporary`   | `black_aluminum`, `champagne_aluminum`, `walnut`, `oak`, `white_wood`, `light_oak`, `silver_aluminum` |
| `scandi`         | `light_oak`, `white_wood`, `oak`, `champagne_aluminum`, `black_wood`                           |
| `japandi`        | `light_oak`, `oak`, `walnut`                                                                   |
| `modern_vintage` | `walnut`, `oak`, `dark_walnut`                                                                 |
| `loft`           | `black_aluminum`, `dark_walnut`, `champagne_aluminum`, `silver_aluminum`                       |
| `neoclassic`     | `walnut`, `gold`, `dark_walnut`                                                                |

## Шаг 3. Жесткие исключения

Исключения применяются в указанном порядке.

| Приоритет | Условие                                                                   | Действие                                                                                                |
| --------: | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
|         1 | Стиль не `neoclassic`                                                     | Удалить `gold` из списка кандидатов.                                                                    |
|         2 | Стиль `neoclassic`                                                        | Удалить все рамы с `material = aluminum`.                                                               |
|         3 | `artwork_type = canvas`                                                   | Оставить только рамы с `material = wood`.                                                               |
|         4 | `artwork_type = volumetric`                                               | Оставить только рамы с `material = wood`.                                                               |
|         5 | `size_profile = extra_large`                                              | Удалить `white_wood`.                                                                                   |
|         6 | `monochrome = monochrome`                                                 | Ограничить список рамами `black_aluminum`, `black_wood`, `white_wood`, `silver_aluminum`.               |
|         7 | `interior_style = loft`, или `lightness = dark`, или `temperature = cold` | Удалить `champagne_aluminum`.                                                                           |
|         8 | `chroma_level = high`                                                     | Ограничить список нейтральными рамами `black_aluminum`, `black_wood`, `white_wood`, `light_oak`, `oak`. |
|         9 | `interior_style = loft`, `artwork_type = watercolor`, `lightness = light` | Ограничить список рамами `black_aluminum`, `dark_walnut`.                                               |

Если исключения с приоритетами 8-9 дают пустой список после предыдущих hard-фильтров, они не применяются.

Правило монохромного изображения не отменяется. Если после предыдущих hard-фильтров в текущем списке нет черной, белой или серебристой рамы, алгоритм заменяет список допустимым резервом:

| Условие | Резерв для монохромного изображения |
| --- | --- |
| `interior_style = neoclassic` | `black_wood`, `white_wood` |
| любой другой стиль | `black_aluminum`, `black_wood`, `white_wood`, `silver_aluminum` |

Для `extra_large` из резерва также удаляется `white_wood`.

## Шаг 4. Приоритетное правило серебряной рамы

После жестких исключений алгоритм проверяет, нужно ли выбрать раму `silver_aluminum`.

Рама `silver_aluminum` выбирается, если одновременно выполняются все условия:

| Параметр | Допустимые значения |
| --- | --- |
| Монохромность | `monochrome` |
| Цветовая температура | `cold`, `neutral` |
| Стиль интерьера | `minimal`, `contemporary` |

Исключения, при которых `silver_aluminum` не выбирается:

| Условие | Причина |
| --- | --- |
| `temperature = warm` | Теплая работа конфликтует с серебряной рамой. |
| `interior_style = japandi` | Для джапанди серебро исключается. |
| `interior_style = modern_vintage` | Для modern vintage серебро исключается. |
| `interior_style = neoclassic` | Для неоклассики серебро исключается. |

Если правило сработало, выбор фиксируется на `silver_aluminum`. Последующие правила дуба, шампани, черной и белой рамы, а также фильтры материала, светлоты и высокой насыщенности не меняют этот выбор.

Если правило не сработало или есть исключение, `silver_aluminum` исключается из списка кандидатов и не может быть выбран старым порядком рам по интерьеру.

## Шаг 5. Приоритетное правило дуба

После правила серебряной рамы алгоритм проверяет, нужно ли выбрать раму `oak`.

Рама `oak` выбирается, если одновременно выполняются все условия:

| Параметр | Допустимые значения |
| --- | --- |
| Стиль интерьера | `scandi`, `japandi`, `contemporary` |
| Цветовая температура | `warm`, `neutral` |
| Светлота изображения | `medium` |

Исключения, при которых `oak` не выбирается:

| Условие | Причина |
| --- | --- |
| `temperature = cold` | Холодное изображение конфликтует с теплым древесным оттенком дуба. |
| `interior_style = loft` | Для лофта дуб исключается. |
| `interior_style = neoclassic` | Для неоклассики дуб исключается. |
| `contrast = high` | Высокий контраст требует более графичного или глубокого решения. |

Если правило сработало, выбор фиксируется на `oak`. Последующие правила шампани, черной, светлого дуба и белой рамы, а также фильтры материала, светлоты и высокой насыщенности не меняют этот выбор.

Если правило не сработало или есть исключение, `oak` исключается из списка кандидатов и не может быть выбран старым порядком рам по интерьеру.

## Шаг 6. Приоритетное правило шампани

После правила дуба алгоритм проверяет, нужно ли выбрать раму `champagne_aluminum`.

Рама `champagne_aluminum` выбирается, если одновременно выполняются все условия:

| Параметр | Допустимые значения |
| --- | --- |
| Светлота изображения | `light`, `medium` |
| Цветовая температура | `warm`, `neutral` |
| Стиль интерьера | `minimal`, `contemporary` |
| Контраст изображения | `low`, `medium` |

Исключения, при которых `champagne_aluminum` не выбирается:

| Условие | Причина |
| --- | --- |
| `lightness = dark` | Темная работа требует более уверенной или глубокой рамы. |
| `temperature = cold` | Холодное изображение конфликтует с теплым металлическим оттенком шампани. |
| `interior_style = loft` | Для лофта шампань исключается hard-фильтром. |
| `monochrome = monochrome` | Для монохромных изображений действует отдельное правило: черный, белый или серебро. |

Если правило сработало, выбор фиксируется на `champagne_aluminum`. Последующие правила черной, светлого дуба и белой рамы, а также фильтры материала, светлоты и высокой насыщенности не меняют этот выбор.

Если хотя бы одно условие правила не выполнено, `champagne_aluminum` исключается из списка кандидатов и не может быть выбран старым порядком рам по интерьеру.

## Шаг 7. Приоритетное правило черной рамы

После правила шампани алгоритм проверяет, нужно ли выбрать черную раму.

Черная рама выбирается, если стиль интерьера входит в разрешенный список и есть хотя бы один визуальный триггер:

| Группа | Условие |
| --- | --- |
| Разрешенный стиль | `minimal`, `loft`, `contemporary` |
| Визуальный триггер | `contrast = high`, или `lightness = dark`, или `monochrome = monochrome` |

Исключения, при которых черная рама не выбирается:

| Условие | Причина |
| --- | --- |
| `lightness = light` | Светлая работа требует более мягкой рамы. |
| `contrast = low` | Низкий контраст не дает достаточного основания для черной рамы. |
| `artwork_type = watercolor` | Акварель не должна получать черную раму по этому правилу. |
| `artwork_type = botanical` | Ботаническая иллюстрация не должна получать черную раму по этому правилу. |
| `interior_style = scandi` | Для сканди черная рама исключается. |
| `interior_style = japandi` | Для джапанди черная рама исключается. |
| `interior_style = neoclassic` | Для неоклассики черная рама исключается. |

Если правило сработало, выбор фиксируется на черной раме:

| Условие | Выбор |
| --- | --- |
| `artwork_type = canvas`, `volumetric`, `engraving` | `black_wood` |
| любой другой допустимый тип работы | `black_aluminum` |

Если правило не сработало или есть исключение, `black_aluminum` и `black_wood` исключаются из списка кандидатов и не могут быть выбраны старым порядком рам по интерьеру.

## Шаг 8. Приоритетное правило светлого дуба

После правила черной рамы алгоритм проверяет, нужно ли выбрать раму `light_oak`.

Рама `light_oak` выбирается, если одновременно выполняются все условия:

| Параметр | Допустимые значения |
| --- | --- |
| Стиль интерьера | `scandi`, `japandi` |
| Светлота изображения | `light`, `medium` |
| Контраст изображения | `low`, `medium` |

Исключения, при которых `light_oak` не выбирается:

| Условие | Причина |
| --- | --- |
| `lightness = dark` | Низкая светлота требует более плотной рамы. |
| `contrast = high` | Высокий контраст требует более графичного решения. |
| `interior_style = loft` | Для лофта светлый дуб исключается. |
| `interior_style = neoclassic` | Для неоклассики светлый дуб исключается. |

Если правило сработало, выбор фиксируется на `light_oak`. Последующее правило белой рамы, а также фильтры материала, светлоты и высокой насыщенности не меняют этот выбор.

Если правило не сработало или есть исключение, `light_oak` исключается из списка кандидатов и не может быть выбран старым порядком рам по интерьеру.

## Шаг 9. Приоритетное правило белой рамы

После правила светлого дуба алгоритм проверяет, нужно ли выбрать белую раму.

Белая рама выбирается, если одновременно выполняются все условия:

| Параметр | Допустимые значения |
| --- | --- |
| Светлота изображения | `light` |
| Контраст изображения | `low`, `medium` |
| Стиль интерьера | `scandi` |

Исключения, при которых `white_wood` не выбирается:

| Условие | Причина |
| --- | --- |
| `lightness = dark` | Низкая светлота требует более плотной рамы. |
| `chroma_level = high` | Высокая насыщенность требует более нейтрального или древесного решения. |
| `contrast = high` | Высокий контраст конфликтует с мягкой белой рамой. |
| `interior_style = loft` | Для лофта белая рама исключается. |

Если правило сработало, выбор фиксируется на `white_wood`. Последующие фильтры материала, светлоты и высокой насыщенности не меняют этот выбор.

Если есть явное исключение, `white_wood` удаляется из списка кандидатов. Если правило не сработало без явного исключения, алгоритм продолжает работу с текущим списком кандидатов.

## Шаг 10. Материал по типу работы

Если приоритетные правила серебра, дуба, шампани, черной, светлого дуба и белой рамы не сработали, алгоритм применяет приоритет материала.

| Тип работы | Предпочтительный материал | Допустимый fallback |
| --- | --- | --- |
| `poster` | aluminum | wood |
| `photo` | aluminum | wood |
| `watercolor` | wood | aluminum |
| `engraving` | wood | aluminum |
| `botanical` | wood | aluminum |
| `canvas` | wood | нет |
| `volumetric` | wood | нет |

Правило:

1. Если среди кандидатов есть рамы с предпочтительным материалом, оставить только их.
2. Если таких рам нет, оставить текущий список кандидатов.
3. Для `canvas` и `volumetric` fallback не применяется: остаются только деревянные рамы.

## Шаг 11. Светлота изображения

Если приоритетные правила серебра, дуба, шампани, черной, светлого дуба и белой рамы не сработали, фильтр светлоты применяется после материала. Он выбирает рамы, чья светлота подходит изображению.

| Светлота изображения | Допустимая светлота рамы |
| --- | --- |
| `light` | `light` |
| `medium` | `medium` |
| `dark` | `dark`, затем `medium` |

Правило:

1. Для `light` оставить только светлые рамы.
2. Для `medium` оставить только средние рамы.
3. Для `dark` сначала оставить темные рамы.
4. Если для `dark` темных рам нет, оставить средние рамы.
5. Если фильтр светлоты дает пустой список, отменить только этот фильтр.

## Шаг 12. Итоговый выбор цвета

После всех фильтров выбирается первый кандидат в текущем порядке.

Если список кандидатов пуст после hard-фильтров, используется резерв:

| Условие | Резервная рама |
| --- | --- |
| `canvas` или `volumetric` | `black_wood` |
| любой другой случай | `black_aluminum` |

## Шаг 13. Размер профиля

Ширина профиля зависит от размерного профиля, заполненности кадра и материала выбранной рамы.

| Размерный профиль | Заполненность кадра | Дерево | Алюминий |
| --- | --- | ---: | ---: |
| `small` | `low` | 15 мм | 10 мм |
| `small` | `medium` | 15 мм | 10 мм |
| `small` | `high` | 20 мм | 12 мм |
| `medium` | `low` | 15 мм | 10 мм |
| `medium` | `medium` | 20 мм | 12 мм |
| `medium` | `high` | 20 мм | 12 мм |
| `large` | `low` | 20 мм | 12 мм |
| `large` | `medium` | 30 мм | 15 мм |
| `large` | `high` | 30 мм | 15 мм |
| `extra_large` | `low` | 30 мм | 15 мм |
| `extra_large` | `medium` | 40 мм | 20 мм |
| `extra_large` | `high` | 50 мм | 20 мм |

Если заполненность кадра неизвестна, используется `medium`.

## Шаг 14. Выход алгоритма

Алгоритм возвращает объект `FrameSpec`.

```yaml
FrameSpec:
  id: string
  name: string
  material: wood | aluminum
  color_family: string
  tone: light | medium | dark
  hex: string
  width_mm: integer
  profile: flat | natural_wood | classic
```

`profile` определяется по выбранной раме:

| Условие | profile |
| --- | --- |
| `material = aluminum` | `flat` |
| `id = gold` | `classic` |
| прочие деревянные рамы | `natural_wood` |

## Дерево решений

В дереве решений нужно показывать:

1. Входные параметры: тип работы, стиль, размерный профиль, заполненность, светлота, насыщенность, монохромность.
2. Нормализованный стиль интерьера.
3. Базовый список рам по интерьеру.

## Ограничения текущей версии

- Алгоритм пока выбирает только из базовой библиотеки рам.
- Золото определяется только интерьерным правилом `neoclassic`; автоматическое распознавание золотых элементов изображения пока не используется.
- Цветовая температура изображения влияет на приоритетные правила `silver_aluminum`, `oak` и `champagne_aluminum`; для остальных рам прямого температурного правила пока нет.
- Реальные артикулы багета, глубина профиля, наличие складских остатков и цена пока не учитываются.
