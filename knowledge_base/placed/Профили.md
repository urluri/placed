# Профили

Документ описывает каталог конкретных профилей багета, которые можно показывать пользователю как варианты внутри уже выбранного алгоритмом цвета рамы.

## Принцип использования

Алгоритм выбора рамы определяет базовый `frame_id`: например `white_wood`, `walnut`, `black_aluminum` или `silver_aluminum`.

После этого интерфейс показывает профили, у которых в поле `frame_ids` есть выбранный `frame_id`. Выбор конкретного профиля пользователем меняет визуализацию и рабочую ширину рамы, но не переписывает сам алгоритм выбора цвета.

Особое правило для черной рамы: если алгоритм выбрал `black_aluminum`, пользователь видит базовый черный алюминий и три деревянных черных уголка. Это сделано намеренно: `black_aluminum` в алгоритме означает выбранное черное оформление, а в UI пользователь может примерить конкретные черные профили.

Renderer использует изображение выбранного профиля как источник фактуры. Если пользователь выбирает конкретный уголок, из его изображения извлекаются горизонтальная и вертикальная рейки, очищаются от белого фона и масштабируются на стороны рамы. Если выбран базовый профиль без изображения, применяется стандартная текстура семейства рамы.

Ограничение по узким деревянным профилям: деревянные профили с видимой шириной менее 20 мм, то есть до 19 мм включительно, показываются только для работ размером до A3 включительно. Ориентация не важна: короткая сторона должна быть не больше 300 мм, длинная — не больше 420 мм. Алюминиевые профили этим правилом не ограничиваются.

Изображения профилей хранятся в двух местах:

- `frontend/public/frame_profiles/images/` — для отображения вариантов в UI.
- `backend/app/assets/frame_profiles/images/` — для рендера на backend, в том числе на деплое Timeweb, где backend может быть собран отдельно от frontend.

## Поля каталога

| Поле | Значение |
| --- | --- |
| `id` | Артикул или код профиля. |
| `name` | Читаемое название для интерфейса. |
| `family` | Визуальная семья профиля. |
| `frame_ids` | Базовые рамы, для которых профиль показывается в UI. |
| `render_frame_id` | Опциональный ID рамы для рендера. Используется, когда профиль показывается внутри другого базового выбора, например черное дерево внутри `black_aluminum`. |
| `material` | `wood` или `aluminum`. |
| `width_mm` | Видимая ширина профиля по лицевой стороне. |
| `height_mm` | Высота профиля. Используется как глубина для спецификации. |
| `image_url` | Путь к изображению уголка в приложении. |
| `source_url` | Ссылка на карточку профиля. |
| `source_page` | Страница исходного PDF. |

## Замечания

- Профили `light_oak` и `oak` используют общий набор из PDF, потому что в исходном документе они объединены как «Дуб/Светлый дуб».
- Для `black_aluminum` дополнительно показываются деревянные черные профили, чтобы пользователь мог примерить разные черные варианты без изменения правила выбора черной рамы.
- Профили `05.21.AL` и `05.32.AL` не показываются в UI. Базовая рама `champagne_aluminum` использует цвет, близкий к профилю `05.32.AL`.
- Файл данных для приложения: `frontend/public/frame_profiles/catalog.json`.
- Изображения профилей: `frontend/public/frame_profiles/images/`.
- Копия изображений для backend-renderer: `backend/app/assets/frame_profiles/images/`.
