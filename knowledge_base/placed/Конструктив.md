# Конструктив оформления

Документ описывает конструктивные элементы оформления: стекло, паспарту, shadow box и базовый размер паспарту. Цвета паспарту и багета определяются отдельными правилами и здесь не описываются.

## Размерные профили

Размерный профиль определяется по физическому размеру работы в миллиметрах. Используется короткая сторона работы.

| Профиль       | Условие по короткой стороне | Примеры форматов                                           |
| ------------- | --------------------------- | ---------------------------------------------------------- |
| Малый         | до 299 мм                   | 100x150, 130x180, 150x200, 200x300, A4 210x297, 300x300    |
| Средний       | от 300 мм и до 400 мм       | 300x400, 300x450, 300x500, 400x500, 400x600,               |
| Большой       | от 401 мм и до 599 мм       | 420x594, 500x500, 500x700, 600x800, 600x900                |
| Очень большой | от 600 мм и более           | 700x1000, 800x1200, 900x1200, 1000x1400, 1200x1800 и более |

Если работа вытянутая, профиль все равно определяется по короткой стороне. Длинная сторона используется для пропорций и физического масштаба превью, но не повышает размерный профиль сама по себе.

## Голосование за паспарту для постера

Для постера паспарту не назначается напрямую. Решение принимается по сумме голосов из двух факторов:

1. Заполненность кадра.
2. Размерный профиль.

### Голоса по заполненности кадра

| Заполненность кадра | Голос |
| --- | ---: |
| Low | 2 |
| Medium | 1 |
| High | -1 |

### Голоса по размерному профилю

| Размерный профиль | Голос |
| ----------------- | ----: |
| Малый             |     2 |
| Средний           |     2 |
| Большой           |     1 |
| Очень большой     |    -1 |

### Итоговое решение

| Сумма голосов | Решение               |
| ------------: | --------------------- |
|    1 и больше | использовать паспарту |
|      меньше 1 | без паспарту          |

## Размер паспарту

Правила применяются для всех типов работ, где паспарту включено.

- Верхний край паспарту равен боковым краям.
- Нижний край паспарту на 10% больше боковых и верхнего края.
- Базовый размер бокового/верхнего края считается как процент от меньшей стороны работы.

| Размерный профиль |               Standard |              Signature |
| ----------------- | ---------------------: | ---------------------: |
| Малый             |                    35% |                    40% |
| Средний           |                    25% |                    30% |
| Большой           |                    15% |                    20% |
| Очень большой     | 10%, но не более 70 мм | 15%, но не более 80 мм |

## Двойное паспарту для Signature

В исполнении `Signature` всегда используется два слоя паспарту:

- верхнее паспарту;
- нижнее паспарту.

Верхнее паспарту считается по таблице "Размер паспарту" выше. Нижнее паспарту располагается под верхним, ближе к работе.

### Размеры нижнего паспарту

Поля нижнего паспарту рассчитываются относительно соответствующих полей верхнего паспарту:

| Поле | Правило |
| --- | --- |
| Левое | 80% от левого поля верхнего паспарту |
| Правое | 80% от правого поля верхнего паспарту |
| Верхнее | 80% от верхнего поля верхнего паспарту |
| Нижнее | 80% от нижнего поля верхнего паспарту |

Видимая внутренняя полоса нижнего паспарту равна разнице между полем верхнего и нижнего паспарту, то есть 20% от соответствующего поля верхнего паспарту.

Работа располагается в окне нижнего паспарту.
