# Цвет паспарту

Документ описывает правила выбора цвета паспарту. Цвет багета определяется отдельными правилами и здесь не описывается.

В проекте остаются два исполнения оформления:

- `Standard`;
- `Signature`.

## Входные параметры

Для выбора цвета паспарту используются результаты анализа изображения:

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Монохромность | монохромное / цветное | Определяет, считать ли изображение черно-белым или почти черно-белым. |
| Температура | теплый / нейтральный / холодный | Показывает общий цветовой тон изображения. |
| Светлота | светлый / средний / темный | Показывает общий уровень яркости изображения. |
| Основной цвет | `PaletteColor` | Самая значимая цветовая масса изображения. |
| Вторичный цвет | `PaletteColor` | Заметный цвет, отличающийся от основного. |
| Акцентный цвет | `AccentColor` | Небольшой выразительный цветовой сигнал. |

## Общие принципы

1. Паспарту не должно разрушать композицию изображения.
2. Для `Standard` паспарту остается спокойным нейтральным полем; для `Signature` нижнее паспарту следует выбранному акцентному цвету изображения.
3. Если расчетный цвет получен из изображения, итоговый цвет выбирается только из палитры placed.
4. Поиск ближайшего цвета выполняется в CIELAB через Delta E.
5. Для MVP можно использовать простую евклидову Delta E. Позже можно заменить ее на Delta E 2000.

## Standard

Для `Standard` используется спокойная белая и теплая нейтральная группа.

Приоритеты:

1. Если изображение монохромное, применяется правило для монохромных изображений вне зависимости от температуры и светлоты.
2. Если изображение цветное, цвет паспарту выбирается по температуре и светлоте.

| Условие | Код | Цвет паспарту | HEX |
| --- | --- | --- | --- |
| Монохромное изображение | PW001 | Museum White | `#F7F6F2` |
| Теплое + светлое | PW003 | Warm White | `#F5F1E8` |
| Теплое + среднее | PW003 | Warm White | `#F5F1E8` |
| Теплое + темное | PW003 | Warm White | `#F5F1E8` |
| Холодное + любая светлота | PW001 | Museum White | `#F7F6F2` |
| Нейтральное + любая светлота | PW001 | Museum White | `#F7F6F2` |

## Signature

В исполнении `Signature` используется два слоя паспарту.

### Верхнее паспарту

Цвет верхнего паспарту определяется так же, как для `Standard`.

### Нижнее паспарту

Цвет нижнего паспарту выбирается напрямую от акцентного цвета изображения.

Базовый принцип:

1. Алгоритм анализа изображения определяет `palette.accent.selected`.
2. Цвет `palette.accent.selected` переводится в CIELAB.
3. Из рабочей палитры placed выбирается ближайший цвет по Delta E.
4. Выбранный цвет placed используется как цвет нижнего паспарту.

Для монохромных и Ч/Б изображений действует тот же порядок: если алгоритм анализа нашел акцентный цвет, нижнее паспарту выбирается по нему, а не приравнивается к верхнему паспарту.

Цвет акцента не корректируется перед поиском в placed:

- светлота не повышается и не понижается;
- насыщенность не приглушается;
- черный, серый или нейтральный акцент не заменяется отдельным резервным цветом;
- акцент не сравнивается с основным и вторичным цветом для выбора другого кандидата.

Если акцентный цвет изображения не определен, используется резервный цвет `PW003` Warm White (`#F5F1E8`).

## Signature: финальный поиск в палитре placed

Цвет `palette.accent.selected` приводится к ближайшему цвету из рабочей палитры placed.

Фильтры перед поиском не применяются: участвуют все цвета, которые сейчас остаются в рабочей палитре placed.

Финальный принцип:

Нижнее паспарту должно максимально близко повторять выбранный алгоритмом акцентный цвет изображения с учетом ограниченного набора цветов placed.
