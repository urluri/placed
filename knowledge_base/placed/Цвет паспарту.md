# Цвет паспарту

Документ описывает правила выбора цвета паспарту. Цвет багета определяется отдельными правилами и здесь не описывается.

В проекте остаются два исполнения оформления:

- `Standard`;
- `Signature`.

## Входные параметры

Для выбора цвета паспарту используются результаты анализа изображения:

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Монохромность | монохромное / цветное | Определяет, считать ли изображение черно-белым или почти черно-белым. |
| Температура | теплый / нейтральный / холодный | Показывает общий цветовой тон изображения. |
| Светлота | светлый / средний / темный | Показывает общий уровень яркости изображения. |
| Основной цвет | `PaletteColor` | Самая значимая цветовая масса изображения. |
| Вторичный цвет | `PaletteColor` | Заметный цвет, отличающийся от основного. |
| Акцентный цвет | `AccentColor` | Небольшой выразительный цветовой сигнал. |

## Общие принципы

1. Паспарту не должно становиться главным акцентом композиции.
2. Паспарту должно поддерживать изображение, но быть спокойнее исходного цвета.
3. Если расчетный цвет получен из изображения, итоговый цвет выбирается только из палитры placed.
4. Поиск ближайшего цвета выполняется в CIELAB через Delta E.
5. Для MVP можно использовать простую евклидову Delta E. Позже можно заменить ее на Delta E 2000.

## Standard

Для `Standard` используется спокойная белая и теплая нейтральная группа.

Приоритеты:

1. Если изображение монохромное, применяется правило для монохромных изображений вне зависимости от температуры и светлоты.
2. Если изображение цветное, цвет паспарту выбирается по температуре и светлоте.

| Условие | Код | Цвет паспарту | HEX |
| --- | --- | --- | --- |
| Монохромное изображение | PW001 | Museum White | `#F7F6F2` |
| Теплое + светлое | PW004 | Ivory | `#EEE6D5` |
| Теплое + среднее | PW003 | Warm White | `#F5F1E8` |
| Теплое + темное | PW003 | Warm White | `#F5F1E8` |
| Холодное + любая светлота | PW001 | Museum White | `#F7F6F2` |
| Нейтральное + любая светлота | PW001 | Museum White | `#F7F6F2` |

## Signature

В исполнении `Signature` используется два слоя паспарту.

### Верхнее паспарту

Цвет верхнего паспарту определяется так же, как для `Standard`.

### Нижнее паспарту

Цвет нижнего паспарту рассчитывается от акцентного цвета изображения.

Базовый принцип:

1. Нижнее паспарту должно повторять характер акцентного цвета изображения.
2. Акцентный цвет не используется напрямую: он смягчается по насыщенности и проверяется по светлоте.
3. Нижнее паспарту должно быть заметным, но не должно становиться главным визуальным акцентом.
4. Итоговый цвет всегда выбирается из палитры placed через ближайший цвет в CIELAB.

Если акцентный цвет изображения не определен, используется резервный цвет `PW004` Ivory (`#EEE6D5`).

## Signature: выбор базового акцента

Акцентный цвет всегда определяется алгоритмом, но не всегда должен напрямую становиться основой нижнего паспарту.

Перед выбором цвета нижнего паспарту для `Signature` акцентный цвет сравнивается с основным и вторичным цветом изображения в CIELAB.

| Проверка | Условие | Решение |
| --- | --- | --- |
| Акцент близок к основному или вторичному | `Delta E <= 22` | Взять из кандидатов акцентного цвета тот, который дальше всего от конфликтующего основного или вторичного цвета. |
| Акцент в той же цветовой семье, что основной или вторичный | `Delta E <= 24` | Взять из кандидатов акцентного цвета тот, который дальше всего от конфликтующего основного или вторичного цвета. |
| Акцент достаточно самостоятельный | Пороги схожести не выполнены | Использовать приглушенный акцентный цвет. |
| Акцент белый или серый | `family = white / grey` или низкая хрома | Использовать `area`-кандидат акцентного цвета, чтобы не добавлять новый нейтральный цвет автоматически. |
| Акцент черный или почти черный | `L < 25` и низкая хрома | Черный не использовать; заменить на графитовый оттенок палитры placed. |

Если выбранный акцент конфликтует только с основным цветом, кандидаты сравниваются с основным. Если конфликтует только со вторичным, кандидаты сравниваются со вторичным. Если конфликт есть и с основным, и со вторичным, выбирается кандидат с максимальной минимальной дистанцией до обоих цветов.

## Signature: коррекция светлоты и насыщенности

После выбора базового кандидата цвет корректируется в CIELAB.

Используется параметр `L` в диапазоне `0-100`.

| Условие | Решение |
| --- | --- |
| `L_accent < 25` | Не использовать цвет напрямую. Сохранить Hue, снизить насыщенность на 10-20%, поднять светлоту в диапазон `L = 30-45`. |
| `L_accent < 25` и цвет почти черный | Заменить на графитовый оттенок placed с целевым диапазоном `L = 25-40`. |
| `25 <= L_accent < 40` | Осветлить примерно на 15-25 пунктов, снизить насыщенность на 10-20%, повторно проверить светлоту. |
| `L_accent >= 40` | Использовать как основу, снизить насыщенность на 10-20%, светлоту менять только при необходимости. |

После первичной коррекции выполняются обязательные проверки:

1. `L_inner >= 25`.
2. `L_inner >= L_image - 20`.
3. Нижнее паспарту не должно быть значительно темнее изображения.
4. Нижнее паспарту не должно создавать более сильный визуальный контраст, чем основные цветовые отношения внутри изображения.
5. Нижнее паспарту не должно становиться самым визуально тяжелым элементом оформления.

Если `L_inner` ниже допустимого порога, цвет осветляется шагами по 5 пунктов и проверяется повторно.

Если контраст нижнего паспарту с изображением получается чрезмерным:

1. снизить насыщенность;
2. при необходимости приблизить светлоту к средней светлоте изображения;
3. повторить проверку.

## Signature: правило серого

Серый цвет не используется автоматически для цветных изображений.

| Условие | Решение |
| --- | --- |
| Изображение цветное, серый отсутствует среди значимых цветов | Серый не использовать. |
| Изображение теплое | Серый не использовать как базовый вариант; выбрать приглушенную версию цвета изображения. |
| Изображение холодное | Серый допустим только если серый или серо-нейтральный оттенок присутствует в палитре изображения. |
| Изображение нейтральное | Серый допустим. |
| Изображение монохромное или черно-белое | Серый допустим. |
| Акцент черный или почти черный | Серый допустим только как графитовая замена черного. |

Основной приоритет для цветных изображений:

1. подходящий цвет из изображения;
2. приглушенная версия этого цвета;
3. нейтральный серый только если он поддержан палитрой изображения или изображение монохромное/нейтральное.

## Signature: финальный поиск в палитре placed

После всех коррекций расчетный цвет приводится к ближайшему цвету из палитры placed.

Фильтры перед поиском:

1. Из палитры исключаются ненейтральные цветовые семьи основного и вторичного цвета изображения, если есть подходящая альтернатива.
2. Семья `grey` исключается для теплых и цветных изображений, если серый не является значимой частью палитры изображения.
3. Для черного или почти черного акцента поиск ограничивается графитовыми оттенками placed (`family = grey`, `role = deep_neutral`).

Финальный принцип:

Нижнее паспарту должно повторять характер акцентного цвета изображения, но быть спокойнее и немного светлее него. Оно поддерживает произведение, а не конкурирует с ним.
