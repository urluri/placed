# Цвет оформления

Документ описывает правила выбора цвета паспарту. Цвет багета определяется отдельными правилами и здесь не описывается.

## Входные параметры

Для выбора цвета паспарту используются результаты анализа изображения:

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Монохромность | монохромное / цветное | Определяет, считать ли изображение ЧБ или почти ЧБ. |
| Температура | теплый / нейтральный / холодный | Показывает общий цветовой тон изображения. |
| Светлота | светлый / средний / темный | Показывает общий уровень яркости изображения. |

## Приоритеты

1. Если изображение монохромное, применяется правило для ЧБ вне зависимости от температуры и светлоты.
2. Если изображение цветное, цвет паспарту выбирается по температуре и светлоте.
3. Если для варианта оформления нет таблицы, используется временный базовый цвет `ivory`.

## Цвет паспарту для Standard

| Условие | Цвет паспарту | Hex |
| --- | --- | --- |
| Монохромное изображение | Museum White | `#F7F6F2` |
| Теплое + светлое | Ivory | `#EEE6D5` |
| Теплое + среднее | Warm White | `#F5F1E8` |
| Теплое + темное | Warm White | `#F5F1E8` |
| Холодное + любая светлота | Museum White | `#F7F6F2` |
| Нейтральное + любая светлота | Museum White | `#F7F6F2` |

## Временное правило для Modern и Signature

Для вариантов `Modern` и `Signature` цветовые таблицы еще не определены.

Пока для них используется временный цвет:

| Вариант | Цвет паспарту | Hex |
| --- | --- | --- |
| Modern | Ivory | `#FFFFF0` |
| Signature | Ivory | `#FFFFF0` |
