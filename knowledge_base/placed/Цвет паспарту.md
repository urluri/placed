# Цвет паспарту

Документ описывает правила выбора цвета паспарту. Цвет багета определяется отдельными правилами и здесь не описывается.

В проекте остаются два исполнения оформления:

- `Standard`;
- `Signature`.

## Входные параметры

Для выбора цвета паспарту используются результаты анализа изображения:

| Параметр | Значения | Назначение |
| --- | --- | --- |
| Монохромность | монохромное / цветное | Определяет, считать ли изображение черно-белым или почти черно-белым. |
| Температура | теплый / нейтральный / холодный | Показывает общий цветовой тон изображения. |
| Светлота | светлый / средний / темный | Показывает общий уровень яркости изображения. |
| Основной цвет | `PaletteColor` | Самая значимая цветовая масса изображения. |
| Вторичный цвет | `PaletteColor` | Заметный цвет, отличающийся от основного. |
| Акцентный цвет | `AccentColor` | Небольшой выразительный цветовой сигнал. |

## Общие принципы

1. Паспарту не должно становиться главным акцентом композиции.
2. Паспарту должно поддерживать изображение, но быть спокойнее исходного цвета.
3. Если расчетный цвет получен из изображения, итоговый цвет выбирается только из палитры placed.
4. Поиск ближайшего цвета выполняется в CIELAB через Delta E.
5. Для MVP можно использовать простую евклидову Delta E. Позже можно заменить ее на Delta E 2000.

## Standard

Для `Standard` используется спокойная белая и теплая нейтральная группа.

Приоритеты:

1. Если изображение монохромное, применяется правило для монохромных изображений вне зависимости от температуры и светлоты.
2. Если изображение цветное, цвет паспарту выбирается по температуре и светлоте.

| Условие | Код | Цвет паспарту | HEX |
| --- | --- | --- | --- |
| Монохромное изображение | PW001 | Museum White | `#F7F6F2` |
| Теплое + светлое | PW004 | Ivory | `#EEE6D5` |
| Теплое + среднее | PW003 | Warm White | `#F5F1E8` |
| Теплое + темное | PW003 | Warm White | `#F5F1E8` |
| Холодное + любая светлота | PW001 | Museum White | `#F7F6F2` |
| Нейтральное + любая светлота | PW001 | Museum White | `#F7F6F2` |

## Signature

Для `Signature` отдельное цветовое правило пока не задано.

Временно используется:

| Вариант | Код | Цвет паспарту | HEX |
| --- | --- | --- | --- |
| Signature | PW004 | Ivory | `#EEE6D5` |

В дереве решений временность этого правила должна быть явно показана.
