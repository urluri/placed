# Renderer transformations

Этот файл фиксирует набор визуальных преобразований, которые были заложены в renderer до возврата к техническому режиму. Сейчас эти эффекты отключаются, чтобы MVP показывал только изображение в черной технической раме без паспарту и дополнительных оформительских решений.

## Бывший графический конвейер

1. Загрузка изображения пользователя
   - Открытие файла через Pillow.
   - Приведение к RGB.
   - Опциональный поворот на 90 градусов по выбору пользователя.
   - Масштабирование изображения в пиксели по физическим размерам в миллиметрах.

2. Расчет геометрии сцены
   - Перевод миллиметров в пиксели через `mm_to_px`.
   - Расчет ширины изображения.
   - Расчет ширины рамы.
   - Расчет полей паспарту: `mat_left`, `mat_right`, `mat_top`, `mat_bottom`.
   - Расчет внешнего прямоугольника работы.
   - Расчет прямоугольника окна, куда вставляется изображение.

3. Фон стены
   - Создание процедурного фона стены.
   - Использовалась легкая текстура вместо плоской заливки.
   - Цель: сделать превью похожим на интерьерную фотографию.

4. Тень от оформленной работы
   - Добавлялась мягкая внешняя тень от всей рамки на стену.
   - Использовались blur, opacity и offset.
   - Цель: визуально отделить объект от фона.

5. Рама
   - Рисовалась через `draw_frame`.
   - Использовалась процедурная текстура дерева.
   - Добавлялись цветовые вариации.
   - Добавлялся bevel по внешней и внутренней граням.
   - Цель: имитировать объемный багет.

6. Паспарту
   - Рисовалось через `draw_mat`.
   - Использовалась бумажная текстура.
   - Добавлялась фаска вокруг окна.
   - Поддерживались разные размеры паспарту по сторонам.
   - Поддерживался внутренний кант через `draw_inner_reveal`.

7. Ambient occlusion внутри окна
   - Добавлялась мягкая тень по внутреннему периметру окна.
   - Цель: создать ощущение глубины между изображением, паспарту и рамой.

8. Тень контакта вокруг изображения
   - После вставки изображения добавлялась небольшая тень около его края.
   - Цель: визуально посадить изображение в окно.

9. Стекло
   - Поверх изображения добавлялся слабый стеклянный эффект.
   - Использовался полупрозрачный слой и диагональный блик.
   - Цель: создать ощущение работы под стеклом.

10. Глобальное освещение
    - На всю сцену накладывался мягкий градиент освещения.
    - Верхняя часть выглядела светлее, нижняя темнее.
    - Цель: уйти от плоской компьютерной картинки.

11. Виньетка
    - Края изображения затемнялись.
    - Цель: приблизить результат к фотографии.

12. Film grain
    - Добавлялся очень слабый шум по всей сцене.
    - Цель: убрать стерильность CG-рендера.

13. Хроматическая аберрация
    - Цветовые каналы слегка сдвигались на 1 пиксель.
    - Цель: имитация оптического несовершенства.

14. Color grading
    - После всех этапов немного повышались контраст, цветность и резкость.
    - Цель: сделать итоговое изображение более выразительным.

## Почему это отключено

На текущем этапе алгоритм подбора оформления сброшен и еще не переопределен. Поэтому renderer не должен самостоятельно создавать ощущение выбранного оформления. Он не должен добавлять паспарту, стекло, цветовые решения, художественные тени, текстуры или эффекты, которые пользователь может принять за рекомендацию.

Текущий режим должен быть техническим:

- изображение пользователя;
- черная рама;
- без паспарту;
- без стекла;
- без декоративных теней;
- без bevel;
- без текстур;
- без постобработки.

## Что можно вернуть позже

Эффекты можно возвращать только после того, как алгоритм явно начнет отдавать соответствующие параметры. Например:

- паспарту можно рисовать только если `mat.enabled = true`;
- стекло можно рисовать только если `glass.type` не равно `none`;
- цвет рамы можно брать только из явно выбранного алгоритмом `frame.hex`;
- текстуры и bevel можно включать отдельными флагами renderer-качества;
- отладочный UI должен показывать, какой именно параметр привел к каждому визуальному эффекту.
