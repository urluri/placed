# Renderer transformations

## Важное правило

Внутренние тени, ambient occlusion и contact shadow по краям окна паспарту не применяются по умолчанию. Их можно возвращать только по прямому отдельному запросу.

Этот файл фиксирует набор визуальных преобразований renderer. Эффекты используются только для качества превью и не принимают решений за алгоритм: renderer рисует только те элементы, которые уже явно переданы в geometry/spec.

## Бывший графический конвейер

1. Загрузка изображения пользователя
   - Открытие файла через Pillow.
   - Приведение к RGB.
   - Опциональный поворот на 90 градусов по выбору пользователя.
   - Масштабирование изображения в пиксели по физическим размерам в миллиметрах.

2. Расчет геометрии сцены
   - Перевод миллиметров в пиксели через `mm_to_px`.
   - Расчет ширины изображения.
   - Расчет ширины рамы.
   - Расчет полей паспарту: `mat_left`, `mat_right`, `mat_top`, `mat_bottom`.
   - Расчет внешнего прямоугольника работы.
   - Расчет прямоугольника окна, куда вставляется изображение.

3. Фон стены
   - В backend-render сейчас не добавляется, чтобы обычное превью и режим "Смотреть в интерьере" не конфликтовали между собой.
   - Интерьерный фон остается задачей frontend-режима просмотра.

4. Тень от оформленной работы
   - Внешняя тень от всей работы не добавляется в backend-render, потому что изображение возвращается без фоновой стены и без дополнительного поля вокруг объекта.
   - Тень от рамы внутрь паспарту не добавляется: она дает паразитные темные полосы в углах на светлых деревянных рамах.
   - Глубина создается фактурой, профилем рамы, внешней окантовкой и CSS-тенью в UI.

5. Рама
   - Рисовалась через `draw_frame`.
   - Для `white_wood`, `light_oak`, `oak`, `walnut` и `dark_walnut` используются реальные текстуры из папки `textures`.
   - Для остальных деревянных вариантов используется процедурная текстура дерева как fallback.
   - Реальные текстуры раскладываются отдельно по сторонам рамы: горизонтальные рейки получают повернутую текстуру, вертикальные - исходную ориентацию.
   - Углы собираются жесткими диагональными miter-масками, чтобы стык сторон рамы оставался видимым без темного размытия в углах.
   - Добавлялись цветовые вариации.
   - Для деревянных рам темные bevel/rabbet-полосы и затемняющий relief не рисуются: текстура должна читаться без дополнительных темных теней, уходящих внутрь углов.
   - Внешний контур деревянной рамы получает тонкую окантовку по периметру, чтобы работа не выглядела плоско.
   - Для очень светлого окрашенного дерева без файла текстуры используется отдельная спокойная painted-текстура без периодических темных полос; добавляется только чистый внутренний край, чтобы `white_wood` не сливался с теплым белым паспарту.
   - Для алюминиевых рам сохраняется отдельный металлический bevel.
   - Цель: имитировать объемный багет.

6. Паспарту
   - Рисовалось через `draw_mat`.
   - Использовалась бумажная текстура.
   - Добавлялась фаска вокруг окна.
   - Фаска паспарту фиксирована как 1.5 мм и не зависит от ширины паспарту.
   - Поддерживались разные размеры паспарту по сторонам.
   - Поддерживался внутренний кант через `draw_inner_reveal`.

7. Ambient occlusion внутри окна
   - Добавлялась мягкая тень по внутреннему периметру окна.
   - Цель: создать ощущение глубины между изображением, паспарту и рамой.

8. Тень контакта вокруг изображения
   - После вставки изображения добавлялась небольшая тень около его края.
   - Цель: визуально посадить изображение в окно.

9. Стекло
   - Поверх изображения добавлялся слабый стеклянный эффект.
   - Использовался полупрозрачный слой и диагональный блик.
   - Цель: создать ощущение работы под стеклом.

10. Глобальное освещение
    - На всю сцену накладывался мягкий градиент освещения.
    - Верхняя часть выглядела светлее, нижняя темнее.
    - Цель: уйти от плоской компьютерной картинки.

11. Виньетка
    - Края изображения затемнялись.
    - Цель: приблизить результат к фотографии.

12. Film grain
    - Добавлялся очень слабый шум по всей сцене.
    - Цель: убрать стерильность CG-рендера.

13. Хроматическая аберрация
    - Цветовые каналы слегка сдвигались на 1 пиксель.
    - Цель: имитация оптического несовершенства.

14. Color grading
    - После всех этапов немного повышались контраст, цветность и резкость.
    - Цель: сделать итоговое изображение более выразительным.

## Текущий диагностический режим

Renderer временно оставляет только геометрию, цвета, изображение пользователя, текстуры рам, текстуру паспарту и один контролируемый профиль рамы.

Цель режима - изолировать источник паразитных затемнений в углах рамы. Все сложные эффекты реалистичности отключены и должны возвращаться только по одному этапу за раз.

Разрешено:

- рисовать паспарту только если `mat.enabled = true`;
- брать цвет рамы только из `frame.hex`;
- брать цвет паспарту только из `mat.outer_color`;
- раскладывать реальные текстуры рам по сторонам багета;
- применять один поперечный треугольный профиль рамы 12°, где внешняя кромка визуально выше внутренней;
- добавлять бумажную текстуру паспарту.

Запрещено:

- самостоятельно добавлять паспарту, если алгоритм его не включил;
- самостоятельно менять цвет рамы или паспарту;
- самостоятельно назначать стекло;
- применять старый relief/bevel, edge-shadow, rabbet-линии и дополнительные контуры рамы;
- применять тени глубины между слоями паспарту и изображением;
- применять стекло;
- применять глобальное освещение;
- применять виньетку;
- применять film grain;
- применять chromatic aberration;
- применять color grading;
- добавлять фоновую стену внутрь backend-render без отдельного режима или флага.
