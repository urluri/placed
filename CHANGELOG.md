# Changelog

Все заметные изменения проекта фиксируются здесь. Сверху идут будущие изменения, ниже - уже сохраненные этапы.

## Unreleased

### Changed
- Для нижнего паспарту `Signature` отменен комплементарный цвет при совпадении акцента с основной/вторичной цветовой группой: теперь выбирается самый дальний кандидат акцента.
- Рендер деревянной рамы очищен от агрессивных полос/царапин: вместо них добавлен мягкий профиль багета с волнообразными и ступенчатыми перепадами высоты.
- Паспарту в renderer получило тонкий объем на переходах `изображение -> паспарту` и `нижнее паспарту -> верхнее паспарту`; нижнее паспарту `Signature` теперь тоже использует бумажную фактуру.
- Renderer получил более объемный профиль рамы, сатиновую текстуру алюминия, усиленную древесную фактуру, бумажную текстуру паспарту и мягкую тень от рамы; цветная аберрация отключена, а `champagne_aluminum` сделан более золотистым.
- Правила выбора рамы уточнены: в неоклассике запрещен алюминий, а монохромные изображения ограничены черными, белыми и серебристыми рамами.
- Выбор рамы подключен к алгоритму из `knowledge_base/placed/Рама.md`: материал, цвет и ширина профиля теперь рассчитываются по типу работы, интерьеру, светлоте, насыщенности, заполненности и размерному профилю.
- Renderer больше не применяет внутренние тени и contact shadow по краям окна паспарту по умолчанию.
- Результат рендера теперь показывается только после полного прохода всех 10 статусов, каждый статус держится 1250 мс.
- Статус рендера перенесен в центр превью и получил разговорные этапы с анимацией багетной мастерской.
- Для нижнего паспарту `Signature` сужены пороги цветовой схожести и добавлен фильтр семейств основного/вторичного цвета при поиске ближайшего цвета placed.
- Для `Signature` добавлена проверка схожести акцентного цвета с основным и вторичным: близкий акцент уходит в приглушенный комплементарный цвет, нейтральный акцент заменяется на `area`-кандидат.
- Геометрия `Signature` приведена к физической модели `Standard`: окно паспарту совпадает, изображение перекрывает окно на 5 мм с каждой стороны, нижнее паспарту занимает внутренние 20% общего поля.
- Убрано затемнение по краю работы для нижнего паспарту `Signature`: renderer больше не накладывает внутреннюю тень на цветное раскрытие.
- `Применить` теперь сразу считает и рендерит `Standard` и `Signature`; переключение исполнения использует уже готовый preview.
- Кнопка `Применить` блокируется, если входные параметры не изменились, и показывает короткую подсказку при наведении.
- Добавлена локальная история последних 15 загруженных изображений с миниатюрами и выбором из выпадающего списка.
- Убрана фаска вокруг окна паспарту в renderer: край паспарту теперь отрисовывается ровнее и спокойнее.
- Убраны tooltip-подсказки из UI, кнопка скачивания превью снова отображается текстом.
- `Signature` получил двойное паспарту: верхний слой выбирается по правилам `Standard`, нижний слой рассчитывается от акцентного цвета и приводится к ближайшему цвету палитры placed.
- Renderer теперь отрисовывает видимую внутреннюю полосу нижнего паспарту для `Signature`.
- Обновлен UI панели управления и зоны превью: тумблер темы, иконки поворота, текстовая кнопка скачивания, бейдж размерного профиля в шапке превью и более спокойная палитра на базе placed.
- Поворот изображения теперь поддерживает два направления: `-90°` и `90°`.
- Добавлены типы работ `Гравюра` и `Ботаническая иллюстрация` с конструктивом бумажных работ: стекло, паспарту, музейное стекло.
- Таблица размера паспарту синхронизирована с `Конструктив.md`: `35/35/40`, `25/25/30`, `15/15/20`, `10/10/15` с лимитами `70/70/80 мм`.
- Размерные профили обновлены согласно `Конструктив.md`: средний начинается с `300 мм`, большой с `401 мм`, очень большой с `600 мм`.
- Обновлен визуальный стиль UI: более спокойные панели, аккуратные состояния кнопок и полей, улучшенная зона превью.
- Добавлен переключатель светлой/темной темы с сохранением выбора в браузере.
- Исполнение `Modern` удалено из проекта. В приложении и документации остаются только `Standard` и `Signature`.
- Документы `Базовое описание.md`, `Конструктив.md`, `Цвет паспарту.md` и `Палитра placed.md` приведены к модели с двумя исполнениями.
- Backend и frontend больше не создают и не показывают вариант оформления `Modern`.

## 2026-08-05

### Changed
- Максимальный размер паспарту для очень больших работ обновлен согласно `Конструктив.md`: `70/80/90 мм`.
- Исправлен ввод чисел в меню `Отладка`: значения таблицы паспарту больше не зажимаются во время набора.
- Таблица размера паспарту обновлена согласно `Конструктив.md`; в UI добавлено меню `Отладка` для ручной настройки процентов и лимитов паспарту.
- Голоса размерных профилей для постера обновлены согласно `Конструктив.md`: малый `2`, средний `2`, большой `1`, очень большой `-1`.
- Пороги классификации заполненности кадра снижены на 10%: `0.22/0.45` -> `0.198/0.405`.
- Размерные профили теперь определяются по короткой стороне работы: малый до 300 мм, средний до 400 мм, большой до 700 мм, очень большой свыше 700 мм.
- Фаска паспарту в renderer теперь фиксирована как 1.5 мм и не масштабируется от ширины паспарту.
- Добавлен расчет монохромности изображения и выбор цвета паспарту для Standard по таблице из `Цвет паспарту.md`.
- Renderer снова использует визуальные улучшения превью: фактуру и фаску рамы, фактуру паспарту, внутренние тени, стеклянный блик, мягкое освещение и легкую постобработку.
- Цвет паспарту временно зафиксирован как ivory (`#FFFFF0`) для всех работ, где паспарту используется.
- Расчет паспарту для очень больших работ обновлен по таблице из `Конструктив.md`: 20/25/30% с ограничениями 120/140/160 мм.
- Порог голосования за паспарту для постера приведен к правилу из `Конструктив.md`: паспарту используется, если сумма голосов 1 и больше.

### Added
- Обновлен режим "Смотреть в интерьере":
  - интерьерные фоны стали более разнообразными и предметными;
  - у всех сцен сохранена общая центральная зона стены для размещения работы;
  - масштаб работы в интерьере теперь считается от внешнего физического размера оформления и единой виртуальной стены 3600 мм.

## 2026-08-04

### Added
- Добавлены конструктивные правила оформления из `knowledge_base/placed/Конструктив.md`:
  - размерные профили `малый / средний / большой / очень большой`;
  - стекло, паспарту и shadow box по типу работы;
  - голосование за паспарту для постера;
  - расчет размера паспарту по размерному профилю и варианту оформления;
  - временный цвет паспарту из вторичного цвета работы.
- Renderer снова умеет отрисовывать паспарту, но только когда оно включено правилами.
- Добавлен UI-слой для работы с физическим размером цифровых изображений:
  - чтение пиксельного размера загруженного файла;
  - автоматический расчет физического размера по 300/200/150 PPI;
  - оценка качества печати по текущему размеру;
  - режимы "Рассчитать по файлу" и "Задать вручную";
  - блокировка пропорций изображения при ручном редактировании.

### Changed
- Упрощен UX выбора физического размера:
  - режим "Рассчитать по файлу" блокирует ручной ввод миллиметров;
  - ручное редактирование доступно только в режиме "Задать вручную";
  - управление пропорциями перенесено к ручному вводу;
  - добавлены tooltip-подсказки и активное состояние выбранного PPI-пресета.
