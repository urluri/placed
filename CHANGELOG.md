# Changelog

Все заметные изменения проекта фиксируются здесь. Сверху идут будущие изменения, ниже - уже сохраненные этапы.

## Unreleased

### Changed
- Добавлены типы работ `Гравюра` и `Ботаническая иллюстрация` с конструктивом бумажных работ: стекло, паспарту, музейное стекло.
- Таблица размера паспарту синхронизирована с `Конструктив.md`: `35/35/40`, `25/25/30`, `15/15/20`, `10/10/15` с лимитами `70/70/80 мм`.
- Размерные профили обновлены согласно `Конструктив.md`: средний начинается с `300 мм`, большой с `401 мм`, очень большой с `600 мм`.
- Обновлен визуальный стиль UI: более спокойные панели, аккуратные состояния кнопок и полей, улучшенная зона превью.
- Добавлен переключатель светлой/темной темы с сохранением выбора в браузере.
- Документы `Цвет паспарту.md` и `Палитра placed.md` приведены к рабочей структуре: для Modern описан подбор через приглушение цвета изображения и поиск ближайшего спокойного оттенка из палитры placed.
- Backend теперь выбирает цвет паспарту для Modern по палитре placed; Signature пока остается на временном Ivory.

## 2026-08-05

### Changed
- Максимальный размер паспарту для очень больших работ обновлен согласно `Конструктив.md`: `70/80/90 мм`.
- Исправлен ввод чисел в меню `Отладка`: значения таблицы паспарту больше не зажимаются во время набора.
- Таблица размера паспарту обновлена согласно `Конструктив.md`; в UI добавлено меню `Отладка` для ручной настройки процентов и лимитов паспарту.
- Голоса размерных профилей для постера обновлены согласно `Конструктив.md`: малый `2`, средний `2`, большой `1`, очень большой `-1`.
- Пороги классификации заполненности кадра снижены на 10%: `0.22/0.45` -> `0.198/0.405`.
- Размерные профили теперь определяются по короткой стороне работы: малый до 300 мм, средний до 400 мм, большой до 700 мм, очень большой свыше 700 мм.
- Фаска паспарту в renderer теперь фиксирована как 1.5 мм и не масштабируется от ширины паспарту.
- Добавлен расчет монохромности изображения и выбор цвета паспарту для Standard по таблице из `Цвет паспарту.md`.
- Renderer снова использует визуальные улучшения превью: фактуру и фаску рамы, фактуру паспарту, внутренние тени, стеклянный блик, мягкое освещение и легкую постобработку.
- Цвет паспарту временно зафиксирован как ivory (`#FFFFF0`) для всех работ, где паспарту используется.
- Расчет паспарту для очень больших работ обновлен по таблице из `Конструктив.md`: 20/25/30% с ограничениями 120/140/160 мм.
- Порог голосования за паспарту для постера приведен к правилу из `Конструктив.md`: паспарту используется, если сумма голосов 1 и больше.

### Added
- Обновлен режим "Смотреть в интерьере":
  - интерьерные фоны стали более разнообразными и предметными;
  - у всех сцен сохранена общая центральная зона стены для размещения работы;
  - масштаб работы в интерьере теперь считается от внешнего физического размера оформления и единой виртуальной стены 3600 мм.

## 2026-08-04

### Added
- Добавлены конструктивные правила оформления из `knowledge_base/placed/Конструктив.md`:
  - размерные профили `малый / средний / большой / очень большой`;
  - стекло, паспарту и shadow box по типу работы;
  - голосование за паспарту для постера;
  - расчет размера паспарту по размерному профилю и варианту Standard/Modern/Signature;
  - временный цвет паспарту из вторичного цвета работы.
- Renderer снова умеет отрисовывать паспарту, но только когда оно включено правилами.
- Добавлен UI-слой для работы с физическим размером цифровых изображений:
  - чтение пиксельного размера загруженного файла;
  - автоматический расчет физического размера по 300/200/150 PPI;
  - оценка качества печати по текущему размеру;
  - режимы "Рассчитать по файлу" и "Задать вручную";
  - блокировка пропорций изображения при ручном редактировании.

### Changed
- Упрощен UX выбора физического размера:
  - режим "Рассчитать по файлу" блокирует ручной ввод миллиметров;
  - ручное редактирование доступно только в режиме "Задать вручную";
  - управление пропорциями перенесено к ручному вводу;
  - добавлены tooltip-подсказки и активное состояние выбранного PPI-пресета.

## 2026-07-30

### Added
- Добавлен опциональный режим "Смотреть в интерьере" в зоне превью.
- Добавлены интерьерные фоновые изображения для всех текущих стилей интерьера.
- Работа в превью может отображаться либо на нейтральном фоне, либо поверх выбранного интерьера.

### Changed
- Renderer теперь отдает только оформленную работу в технической черной раме без собственной фоновой стены.

## 2026-07-29

### Added
- Добавлен расчет характеристик изображения:
  - основной цвет;
  - вторичный цвет;
  - акцентный цвет;
  - цветовая температура;
  - светлота;
  - насыщенность;
  - заполненность кадра;
  - контраст.
- Добавлена структурированная логика выбора акцентного цвета с несколькими кандидатами.

### Changed
- Удалена лишняя метрика монохромности.
- Подстроена эвристика выбора акцентного цвета на тестовых изображениях.

## 2026-07-28

### Changed
- Старая логика рекомендаций отключена.
- Проект возвращен к техническому оформлению: черная рама без паспарту и стекла.
- UI очищен от старых артефактов алгоритма оформления.

### Removed
- Удалены старые документы алгоритма и файл правил.

## 2026-07-27

### Added
- Проект разделен на frontend и backend.
- Backend подготовлен как FastAPI-сервис.
- Frontend подготовлен как React/Vite-приложение.
- Добавлены health endpoints для деплоя.

### Fixed
- Исправлены проблемы деплоя backend на Timeweb Cloud App Platform.
- Исправлены проблемы с кэшированием и устаревшими результатами превью.
- Добавлена кнопка "Применить", чтобы рендер не запускался автоматически.
